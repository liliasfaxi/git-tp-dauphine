Ces outils ne sont pas au programme du module. Les connaître de nom
vous suffira pour savoir quoi chercher le jour où vous en aurez besoin.

### Réécrire l'historique

| Commande | Ce qu'elle fait |
|---|---|
| `git commit --amend` | Je corrige le dernier commit |
| `git rebase main` | Je rejoue mes commits au-dessus de `main` |
| `git cherry-pick <sha>` | Je prends **un seul** commit d'une autre branche |
| `git revert <sha>` | J'annule un commit en en créant un nouveau |

{: .warning }
> Ces commandes **réécrivent l'historique**. Ne les utilisez jamais sur
> des commits déjà poussés et partagés avec d'autres.

### Retrouver ce qu'on croyait perdu

| Commande | Ce qu'elle fait |
|---|---|
| `git reflog` | La liste de tout ce que vous avez fait, même annulé |
| `git restore <fichier>` | J'annule mes modifications non validées |

### L'écosystème GitHub

| Outil | À quoi ça sert |
|---|---|
| **GitHub Actions** | Lancer des tâches automatiquement : tests, déploiement |
| **GitHub Pages** | Publier un site depuis un dépôt |
| **Codespaces** | Un environnement de développement dans le navigateur |
| **github.dev** | Un éditeur ouvert en tapant `.` sur un dépôt |
| **Copilot** | Un assistant de rédaction de code |
| **GitHub Desktop** | Une interface graphique, pour ceux qui préfèrent |
