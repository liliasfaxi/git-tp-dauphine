## Fusionner
{: .d-inline-block }

Séance 8
{: .label .label-blue }

| Commande | En français |
|---|---|
| `git switch main` | Je vais sur la branche qui doit **recevoir** |
| `git merge <branche>` | J'y intègre l'autre branche |

**On fusionne toujours vers la branche où l'on se trouve.**

| Type de fusion | Quand |
|---|---|
| Fast-forward | `main` n'a pas bougé depuis : le pointeur avance, aucun commit créé |
| 3-way merge | Les deux branches ont avancé : Git crée un commit de fusion |

### Un conflit

```
<<<<<<< HEAD
la version de la branche où je suis
=======
la version de la branche que j'intègre
>>>>>>> nom-de-la-branche
```

Un conflit n'est pas une erreur : c'est une question que Git vous pose.

1. Ouvrez le fichier, choisissez ce qui doit rester
2. **Supprimez les trois lignes de marqueurs**
3. `git add <fichier>`
4. `git commit`

| Commande | En français |
|---|---|
| `git merge --abort` | J'annule tout, je reviens avant la fusion |
| `git status` | Quels fichiers sont encore en conflit ? |
