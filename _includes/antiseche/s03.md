## Authentification
{: .d-inline-block }

Séance 3
{: .label .label-blue }

| Commande | Ce qu'elle fait |
|---|---|
| `ssh-keygen -t ed25519 -C "adresse"` | Je fabrique ma paire de clés |
| `ssh-add ~/.ssh/id_ed25519` | Je charge ma clé dans l'agent |
| `cat ~/.ssh/id_ed25519.pub` | J'affiche ma clé **publique** |
| `ssh -T git@github.com` | Je teste ma connexion à GitHub |

La clé **publique** (`.pub`) se donne à GitHub.
La clé **privée** ne quitte jamais votre machine.

Réponse attendue au test : `Hi <votre-nom>! You've successfully authenticated`.
