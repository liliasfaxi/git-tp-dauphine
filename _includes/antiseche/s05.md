## Se synchroniser
{: .d-inline-block }

Séance 5
{: .label .label-blue }

| Commande | En français |
|---|---|
| `git fetch` | Va voir ce qu'il y a de neuf, sans rien changer chez moi |
| `git pull` | Va voir, **et** intègre chez moi |
| `git push` | Envoie mon travail |

`git pull` = `git fetch` + `git merge`.

### Quand un push est rejeté

```
! [rejected] main -> main (fetch first)
```

Ce n'est pas une erreur : quelqu'un a poussé avant vous.

```
git pull
```

puis, une fois l'intégration faite :

```
git push
```

**Le réflexe : `git pull` avant chaque `git push`.**
