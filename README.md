Ceci est le TP sur Git & Github 

Au début de chaque séance, pour afficher le contenu du TP progressivement:

    - Sur la page du TP en question (par exemle `tp02-authentification.md`), mettre `published = true` (ligne 4).
    - Dans `_config.yml`, incrémenter de 1 la valeur de `seance` (ligne 12).

Valider et publier:

```
    git commit -m "Publication du TP x"
    git push
```
