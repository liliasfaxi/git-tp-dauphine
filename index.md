## Comment fonctionne ce site

Chaque séance a sa page de TP. **Elle apparaît ici le jour de la séance**,
pas avant. Le sommaire à gauche se remplit donc au fil du semestre.

Tous les blocs de code de ce site ont un bouton de copie en haut à droite.
Utilisez-le : il évite les fautes de frappe, et surtout les guillemets
courbes qui font échouer les commandes sans qu'on comprenne pourquoi.

{: .warning }
> Ne copiez jamais une commande sans l'avoir lue.

## Le projet du semestre

Nous travaillons tous sur le même site : **Guide de Survie — Dauphine Tunis**,
un recueil de conseils pratiques écrits par les étudiants.

Vous n'avez pas besoin de savoir développer. Chaque modification à faire
vous est donnée mot pour mot. Ce qui compte ici, ce n'est pas le code :
c'est ce que vous faites avec Git autour du code.

[Voir le dépôt du projet](https://github.com/liliasfaxi/guide-survie){: .btn .btn-primary }

---

## Ce dont vous avez besoin

- un ordinateur portable, le même à chaque séance ;
- Git installé (nous le ferons ensemble en séance 1) ;
- un compte GitHub (nous le créerons aussi) ;
- un éditeur de texte. **VS Code** est recommandé et gratuit.
